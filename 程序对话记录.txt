【初始状态】
- 用户提供文件：hunyuan_standalone_window.html
- 原程序功能：简单的 iframe 包装器，包含状态栏、加载提示、F5刷新
- 原文件大小：约 131 行，基础功能

【用户需求确认】
1. 端适配：三端自适应（网页HTML、手机端、电脑端）
2. 使用模式：单人使用
3. 优化重点：全面优化（UI美化 + 功能增强 + 性能优化 + 预留接口）

【优化方案】
✓ UI全面升级 - 2027科技感深色霓虹风格
  - 深蓝紫渐变背景 + 动态光晕动画
  - 毛玻璃导航栏 (backdrop-filter blur)
  - 青/紫/粉霓虹光效边框与按钮
  - 加载旋转光环 + 进度条
  - 流畅过渡动画

✓ 程序信息展示
  - 左上角 Logo 悬停显示：程序名称、大小、修改时间
  - 作者：军哥懂保
  - 微信号：xunijiayuan（底部状态栏常驻显示）

✓ 增强工具栏
  - 后退/前进导航（Alt+←/→）
  - 刷新（F5）
  - 地址栏（可编辑跳转，回车确认）
  - 新窗口打开
  - 全屏模式（F11）
  - 帮助按钮（带？角标）

✓ 使用说明 & 名词解析
  - 侧边面板三标签：使用说明 / 名词解析 / 历史记录
  - 6 个专业词汇大白话解析（HTTPS、实时生图、iframe、历史记录、全屏、预留接口）
  - 快捷键一览表

✓ 历史记录功能
  - localStorage 持久化存储（最多50条）
  - 一键跳转 / 单条删除 / 清空全部
  - 显示访问时间

✓ 预留外部接口
  - window.HunyuanApp 全局对象（navigate/refresh/fullscreen等）
  - postMessage 跨窗口通信
  - 支持事件订阅

✓ 三端响应式
  - 桌面端（≥1400px）：加宽间距，更大标题
  - 平板端（≤768px）：隐藏标题文字，紧凑布局
  - 手机端（≤480px）：极简布局，隐藏次要信息

✓ 加载与错误处理
  - 加载动画 + 进度条模拟
  - 加载耗时统计
  - 错误状态提示 + 一键重试
  - 状态指示灯（就绪/加载中/错误）

【技术要点】
- 单文件 HTML，内联 CSS + JS，无需额外依赖
- 深色主题科技感设计，符合2027商用审美
- 全中文界面，无英文
- sandbox 安全沙箱配置
- localStorage 本地存储，不上传服务器
