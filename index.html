使用说明

🎯 程序简介

本程序是「腾讯混元实时生图」的独立桌面窗口封装，让您在一个干净的界面中专注使用 AI 绘图功能，无需打开浏览器。

🚀 核心操作

  • 刷新页面：点击 ↻ 按钮或按 F5
  • 全屏模式：点击 ⛶ 按钮或按 F11，沉浸式绘图
  • 新窗口打开：点击 ⧉ 在系统浏览器中打开当前页面
  • 地址跳转：在地址栏输入网址后点击 ➤ 或回车
  • 前进/后退：点击 ◀ ▶ 或按 Alt+←/→

💡 使用技巧

💡 提示

侧边面板会记录您访问过的网址，可在「历史记录」标签中一键跳转或删除。程序信息（大小、修改时间、作者）可点击左上角 Logo 查看。

⚡ 快捷键一览

  • F5 — 刷新当前页面
  • F11 — 切换全屏
  • Alt + ← — 后退
  • Alt + → — 前进
  • Esc — 退出全屏 / 关闭面板
  • Ctrl + H — 打开历史记录
🔒 HTTPS 安全连接
地址栏左侧的小锁表示当前连接是加密的，您在页面上输入的内容（如提示词）会被加密传输，不用担心被第三方窃取。
🎨 实时生图
指 AI 根据您输入的文字提示词，实时生成对应图片的功能。您可以一边修改描述，一边看到图片的变化。
🖼️ iframe 内嵌框架
本程序用 iframe 技术把混元生图网页嵌入到本地窗口中，相当于在应用里开了一个专用浏览器，不影响您其他浏览器的使用。
💾 历史记录
程序会把您访问过的网址保存在本地浏览器存储（localStorage）中，不会上传到服务器。可以随时删除或清空。
⛶ 全屏模式
隐藏顶部工具栏和底部状态栏，让绘图区域占满整个屏幕，获得更大的创作空间。按 Esc 或 F11 退出。
🔌 预留接口
程序对外暴露了 window.HunyuanApp 对象，其他程序可以通过它调用刷新、跳转、获取历史等功能，方便二次集成。
